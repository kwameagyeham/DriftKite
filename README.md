# DriftKite

DriftKite enables Cloud-based, Intelligent data aggregation and real-time processing within an Autonomous System Platform.

With DriftKite, you get a lightweight tool that stays out of your way.

**What you get**

- DriftKite enables Cloud-based, Intelligent data
- aggregation and real-time processing within
- an Autonomous System Platform

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DriftKite.git`
2. `cd DriftKite`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DriftKite, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
